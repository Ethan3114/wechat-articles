# 亏损数百亿的AI巨头，凭什么撑起两万亿美元上市神话

在硅谷资本市场的聚光灯下，一家年轻的科技公司正准备打破全球科技史上的上市纪录。
不久前，Anthropic 正式向美国证券交易委员会递交了招股文件，计划以代码 ANT 登录纳斯达克。华尔街多方机构给出的公开估值预期，直接锁定在 1.5万亿至2万亿美元。
这本该是一场毫无争议的商业加冕，但招股书首页摊开的财务数字，却让许多普通投资者倒吸了一口凉气。
在 2026 年的前六个月里，这家公司的实际收入展现出了近乎恐怖的爆发力，半年营收突破 163亿美元，比起上年同期的 11.6 亿美元猛增了接近十四倍。但在利润那一栏，赫然印着一个高达 807亿美元 的净亏损。
收入暴涨十四倍，亏损却数倍于收入。这种巨大的财务反差，不仅没有吓退挑剔的投行，反而引来了史上最密集的资本追捧。
华尔街账本上的八百亿美元纸面亏损
要读懂这场超大规格的资本盛宴，必须先拆开那笔让人心惊肉跳的巨额亏损。
普通人看到 807 亿美元的亏损，第一反应往往是这家公司正在疯狂挥霍现金。但翻开详细账目就会发现，其中有整整 724亿美元 根本没有流出公司的银行账户，它只是一笔停留在纸面上的会计计提。
这笔庞大数字的真正来源，是早期亚马逊等战略伙伴注资时签署的可转换票据与未来股权协议。按照通用会计准则的要求，当一家创业公司的公允估值从数百亿美元一路狂飙到两万亿美元时，这些早期投资协议里所附带的转股权益价值也跟着成倍膨胀。在账面上，公司必须把这种由估值暴涨带来的权益增值，原原本本地计提为自己的纸面负债变动。
公司越是被市场狂热看好、未来估值涨得越高，账本上记录出来的纸面亏损反而越是惊人。

如果把这笔不涉及实际现金流出的纸面项目拿掉，公司上半年在服务器集群、芯片算力与网络带宽上的真实硬性开销接近 90 亿美元。面对半年 163 亿美元的真金白银进账，它的日常经营现金流已经非常充裕。
更重要的是，这 163 亿美元并不是依靠低价倾销换来的虚胖流量，而是全球数以万计的企业客户与开发者，用信用卡和真金白银逐月堆出来的工程消耗。
大洋彼岸的普通人也许还在把各种聊天软件当成写诗、翻译或者搜资料的新鲜玩具，但在真实的软硬件世界里，大批极客与普通开发者早已拿起名为 Claude 的工具，悄悄干出了一系列匪夷所思的事情。
局域网里的反击，一台老电视如何被彻底删掉开机广告
很多人家里都有一台花了几千块钱买回来的智能电视。
但在把这台大屏幕搬进客厅之后，真正的烦恼才刚刚开始。每次按下遥控器电源键，屏幕上都要雷打不动地播放长达几十秒、根本无法按返回键跳过的商业广告。更让人恼火的是，主页里塞满了琳琅满目的收费推荐，后台常驻着大量不知名的程序，买回家才一两年的电视，按一下遥控器都要卡顿半天。
以往想要彻底清理这些系统毒瘤，需要极为专业的安卓系统知识，稍不留神删错一个核心控制文件，整台电视就会陷入无限死机或黑屏重启。
不久前，海外开发者社区里诞生了一个名为 CleanYourTV 的热门开源项目。大批完全没有深厚代码经验的普通用户，开始借助 Claude Code 在家庭局域网里展开了一场针对电视厂商的安静反击。
整个过程简单得近乎不可思议。用户只需要在电视的设置菜单里打开局域网调试开关，连上家里的无线网络，随后在电脑终端里敲下一行自然语言指令，剩下的繁复事务全由模型接管。
cleanyourtv-before-after.jpg
电视去广告前后对比，上方为原厂杂乱系统，下方为清理后极简桌面

它就像一位不知疲倦的驻场运维工程师，在短短两分钟内把电视内部隐藏的 140 多个出厂预装包全部扫描出来。面对成堆晦涩的英文包名，模型能够精准甄别出哪一个是负责弹窗广告的后台插件，哪一个是偷偷收集遥测数据的上报程序，而哪几个绝对不能碰的才是负责屏幕色彩、遥控器信号与声音输出的核心命脉。
最巧妙的地方在于，它并没有粗暴地从底层强行删除文件，而是通过系统自带的用户安全通道，把几十个广告进程逐个送入深度休眠，随后为电视安装上极其干净轻快的极简桌面。
普通人不再需要向厂商妥协，只需几句大白话，就能把自己花钱买来的设备主权完整夺回。
改完之后的电视彻底告别了开机倒计时，按下按键瞬间点亮屏幕，那些多年来寄生在硬件里的隐形程序被彻底清理干净。
十六天在浏览器里造出一颗星球
如果说给家电去广告还属于日常生活里的实用操作，那么在数字创意领域，普通人正在凭借这个工具跨越原本不可逾越的技术天堑。
在游戏行业，把一个知名故事做成一款能自由探索的立体互动游戏，向来是一项极其沉重的大工程。即便是小型团队，也往往需要资深程序员搭建骨架、美术设计师捏造三维角色、关卡策划设计互动，耗时数月才能拿出一个粗糙的原型。
独立创作者 Sac 却凭借一己之力，把世界经典文学作品《小王子》打造成了一款可以在浏览器里直接游玩的立体游戏《小王子：星辰之旅》（The Little Prince: Across the Stars）。
整整十六天，这是他完成整部作品的全部耗时。
little-prince-game.jpg
Sac 借助 Claude 打造的《小王子：星辰之旅》浏览器实机探索画面

玩家不需要下载几个G的庞大安装包，在手机或电脑浏览器里点开网址，就能立刻化身为那个系着围巾的小王子，漫步在拥有独立引力的 B-612 迷你星球上，身边环绕着盛开的玫瑰花、小巧的火山与散落的星尘。
在这场创作实验里，人类作者负责构思剧情脉络与视觉氛围，而复杂的程序逻辑全由 Claude 扛下。从让角色紧贴球形曲面奔跑的引力数学算法，到镜头围绕星球平滑旋转的轨迹控制，再到跨越各个星球时的剧情触发逻辑，全都是通过一段段自然对话持续写就。
遇到画面掉帧或者角色动作穿模时，作者只要把现象直接描述给它，模型就能在数十秒内翻阅上千行前端逻辑，精准挑出数值溢出的漏洞并给出修复方案。
过去阻碍普通人将灵感转化为现实的复杂工程壁垒，第一次被压缩成了随叫随到的代码流水线。
经典的文学 IP 正在以极低的成本，变成普通人触手可及的互动世界。
把主机独占游戏一行行搬进手机
最让极客圈子感到震撼的突破，发生在一个技术壁垒更高、更封闭的领域，那就是商业主机游戏的逆向重构。
很多玩家都知道，像任天堂 Switch 这样的游戏掌机，上面的独占游戏通常只能在官方专门定制的硬件架构上运行。过去如果想在手机或者电脑上玩到这些游戏，唯一的办法是使用模拟器。但模拟器在运行时需要实时把掌机指令翻译成手机指令，不仅手机会迅速发烫降频，画面也极易掉帧卡顿。
近期，以 D2R Mobile 为代表的开源项目彻底打破了这种限制。有开发者利用 Claude 处理复杂代码的耐力，把商业大作《暗黑破坏神2：狱火重生》以原生程序的方式完整搬到了苹果手机上。
d2r-iphone-native.jpg
D2R Mobile 在 iPhone 上原生流畅运行暗黑破坏神2实机效果与触控按键

开发者完全抛弃了卡顿的传统模拟器方案，直接在移动端完成了底层代码的原生重构。游戏直接调用苹果手机的图形芯片，在屏幕上跑出了极其稳定的 60帧满血表现，耗电和发热表现甚至优于大部分原生手游。
将成千上万个底层函数从专用的掌机环境迁移到通用手机环境，原本需要一个资深逆向团队花费数年时间手工排查。开发者为 Claude 编写了专属的任务处理流程，让它日以继夜地阅读导出的底层机器逻辑。
模型耐心地重构着每一条图形接口，把掌机独有的渲染指令翻译成现代移动设备通用的图形语言，甚至还顺手帮开发者重新设计了一整套贴合手机屏幕的触控虚拟摇杆与技能按键布局。
AI 展现出的已经超越了简单的问答能力，而是能够直接解构并重写既有软件世界的超级耐力。
从删掉电视广告、十六天造出一颗童话星球，再到把专业主机游戏搬进掌心，这些由普通人在卧室和书房里捣鼓出来的惊人案例，最终汇聚成了华尔街交易终端上跳动的庞大数据。
当一家公司的产品正在成为成千上万普通人改造现实世界的数字重武器，账面上由估值暴涨引发的那几百亿美元纸面亏损，在追逐未来的万亿资本眼中，早已变成了再划算不过的入场门票。
