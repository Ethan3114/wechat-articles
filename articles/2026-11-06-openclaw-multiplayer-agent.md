# 龙虾突然撕掉单人标签，整个科技圈的Agent可能都要换一种活法

旧金山的 GitHub Universe 现场，展台前挤满了全球各地的极客。
主创头上戴着搞怪的螃蟹发箍，手上套着大红龙虾手套，桌上摆着两台普普通通的笔记本。
谁也没想到，现场两次极其随意的敲击，直接让台下围观人群连续爆出整整十一次惊呼。
开源圈那只凶猛的红龙虾，在 2026年11月5日 突然给全球开发者砸来了一记重锤。
01.jpg

说实话，看到那个现场演示的时候，我整个人都从工位上坐直了。
两台电脑连着同一个 OpenClaw 智能体。
展台大屏幕上实时渲染着旧金山要塞大楼的虚幻引擎三维场景。
现场工作人员随便拉来一位路过的开发者，让他在第一台电脑上输入增加一个自由女神像。
让人头皮发麻的一幕发生了。
敲击键盘的那个哥们甚至还没来得及按回车，旁边的第二台笔记本屏幕上，光标就已经在实时跳动，一字不差地同步吐出每一个英文字母。
02.jpg

按下回车的几秒钟后，那座略显粗糙的自由女神像在虚拟海湾前拔地而起。
紧接着，另一个人走到了第二台电脑前，随手敲下一句把它放大三倍。
第一台电脑的屏幕再次毫秒级同步浮现出这段文字。
回车落下，雕像瞬间膨胀了整整三倍。
没有重新复制任何上文。
没有向智能体解释究竟是哪个雕像。
甚至根本不需要人工做任何背景交代。
两个人隔着不同的机器，在同一个操作空间里，操纵着同一个智能体大脑，把活儿给干完了。
围观人群里有人脱口而出，这要是完全免费，你们这软件到底凭什么这么猛？

过去两三年，整个科技界都在陷入一种近乎狂热的单兵崇拜。
各种发布会都在拼命鼓吹一个超级个体干翻整个团队的故事。
很多程序员和产品经理以为只要配齐了顶级模型，自己一个人就能承包整条流水线。
大企业花了数十年时间试图拆掉部门墙，好不容易让大家坐在一个会议室里通气。
各路智能体横空出世之后，大伙忽然发现，部门墙非但没有塌，反而被水泥浇得更厚了。
03.jpg

现在的真实办公室景象荒诞得让人发笑。
技术团队手里攥着专属的代码助手，产品经理用着自己调教的分析工具，运营和设计各有一套提示词库，财务那边甚至在机房里用一台噪音堪比吹叶机的大机器硬跑本地小模型。
大家各用各的模型，各建各的上下文，自顾自地提示词冲浪。
行业以为自己发明了最新的生产力，结果只是发明了一种极其高雅的互不搭理方式。
灾难往往发生在跨部门真正需要协作的那一刻。
比如产品经理拿着自己的智能体跑出了一份长达几十页的交互方案，兴冲冲地跑去给研发交接。
研发打开自己的智能体，试图把产品给的文档扔进去让模型消化。
上下文在这场信息二道贩子的倒手过程里疯狂丢失，关键约束直接被吞噬，两个人的模型开始在同一个项目里左右互搏。
04.jpg

日常沟通逐渐演变成了法庭对簿公堂。
产品经理像控方原告，坚称自己上周就已经把细节说清楚了。
技术人员像辩方律师，指着代码坚决咬定模型根本没接到这套约束。
如果两个团队各自依靠独立的智能体在信息孤岛里狂奔，最终碰撞出来的必定是一场巨大的人间车祸。
大家过去以为给每个人发一个全能助手就能拯救效率。
现实却狠狠扇了一记耳光，单兵作战的武器越锋利，团队协同的沟壑就越难以逾越。
这只大红龙虾这次扔出的多人联机模式，就是冲着这个巨大的烂摊子去的。

很多人刚听到多人智能体这个词，下意识会觉得这又是一个套壳的噱头。
只要去扒一扒他们在 GitHub 上开源的真实底层实现，就会发现架构设计相当干脆利落。
它完全抛弃了那种把多个人塞进同一个网页对话框的简陋搞法。
支撑起这一套联机协同的核心，是一个名为 Gateway 的常驻网关守护进程。
这个网关默认运行在本地的 18789 端口上，充当整个团队的神经中枢。
05.jpg

在安全哲学上，它确立了一个极其明确的单信任边界准则。
既然能坐在一起协同攻坚，团队成员之间就具备天然的互信基础。
它直接借由 Cloudflare Access 或者 Tailscale 打通零信任内网，通过团队绑定的真实 GitHub 账号进行身份锚定。
谁在什么时候敲了哪行提示词，在底层账本里一清二楚。
最精妙的地方在于它的会话归属模型，它把每一次协同操作硬生生拆解成了三层严密关系。
第一层是无法篡改的创建者，记录任务最初由谁发起。
第二层是能够动态流转的负责人，就像在代码仓库里指派责任人一样。
第三层是所有参与过提示词输入的操作者历史列表。
06.jpg

当任务最终演化为一次代码提交时，系统会自动在提交记录末尾追加每一个参与者的联名贡献者标签。
每一次敲击键盘的功劳都能被精准确权，每一处改动的责任都能追溯到具体的人。
在交互层面上，为了防止两个人同时发送冲突指令把智能体逼疯，它构建了一个共享请求队列与实时感知体系。
你在键盘上打字的瞬间，前端只把输入状态作为临时草稿广播给队友，完全不消耗任何模型算力。
直到你真正敲下回车，指令才会排队进入共享队列。
智能体是在思考还是在执行，大伙在各自屏幕前看得明明白白。
image.png

更让人安心的是它的安全防御机制。
如果团队拉来了一个外部临时合作的访客，系统会在网关内部通过访问控制策略，强行把访客的新会话扔进完全断网的独立容器沙箱。
访客可以在沙箱里查看全局上下文，可以调动模型写测试用例，但他的一举一动绝不会影响到宿主机的核心环境。
07.jpg

整个架构没有丝毫虚头巴脑的花招。
用最标准的工业级通信协议，把一群各自为政的打工人硬生生焊死在同一个思维齿轮上。

如果把视野从代码细节拉升到整个行业的路线之争，这只龙虾的举动堪称对所谓主流共识的一次无情讽刺。
回顾过去这一年多，资本市场和创业圈最喜欢讲的故事是什么？
是多智能体虚拟公司。
无数演示视频里，屏幕上密密麻麻排列着十几个虚拟角色，一个当产品经理，一个当架构师，一个当程序员，一个当局外人测试员。
创始人只要在输入框里输入做个商城，这群虚拟员工就开始疯狂互相回复、开会、反思、打架。
无数开发者满怀期待地跑了几天，最后换来的除了一堆毫无意义的死循环套话，就是几千美元瞬间蒸发的云端账单。
08.jpg

那种把一群虚假人格关在黑盒子里自娱自乐的模式，把整个人工智能产业带进了死胡同。
真实的软件工程和企业生产严肃而残酷。
最难以捉摸的变量永远在代码之外，在于团队里活生生的人到底想要什么。
把真人驱逐出智能体工作流是一条彻底走歪的死路，把多个真人聚拢在同一个强大智能体面前才是破局的正轨。
OpenClaw 这次交出的答卷，本质上是在做智能体时代的协同设计软件。
当年单机设计工具横行天下的时候，大伙互相传递着各种最终版和打死不改版的本地文件，苦不堪言。
直到协同画布横空出世，把所有设计师、产品经理和客户直接拽进同一个画板，让所有光标在同一片空间里起舞，时代的齿轮才真正完成了换挡。
09.jpg

现在的智能体领域，正处于完全相同的临界点。
OpenClaw 基金会内部已经有超过 50 名全职维护者和核心贡献者，全天候泡在这个共享环境里提代码和改补丁。
他们用自己的真实肉身验证了一件事。
当产品人员提出一个天马行空的需求时，技术人员不需要等会议开完再去敲代码。
他可以直接在智能体的共享会话里随手加一行技术边界约束。
两个人看着智能体在屏幕中央实时吐出满足双方共识的工程代码。
这一刻，AI 不再是彼此隔绝的防空洞，它变成了架在两个工位之间最稳固的桥梁。

更让很多闭源商业软件汗流浃背的，是这只龙虾的开源底色。
它顶着极其宽松的 MIT 开源许可，全球代码仓库里的派生分支已经突破了惊人的 83000 次。
它不仅完全免费，而且彻底放开了底层模型的选择权。
你喜欢闭源的顶级逻辑，直接接商业大模型接口。
你偏爱开源的自由可控，接国产强力基座或者在本地塞一个开源模型，照样跑得飞起。
10.jpg

它不捆绑任何云服务，你可以部署在自己的便携笔记本上，也可以挂在月付几十块钱的廉价云服务器里。
你可以把它大卸八块，顺着自己的业务血脉重新缝合出专属的怪物形态。
当某些大厂还在为每人每月几十美元的协同办公订阅费绞尽脑汁算计人头时，开源社区已经把一把毫无保留的重锤塞到了每一个打工人手里。
这场由一只龙虾掀起的多人联机风暴，真的会顺理成章地重构全球所有的协同体系吗？
前方的道路显然还有不少暗礁。
在高度互信的极客开源小队里，这种同屏打字的模式可以跑得极度丝滑。
可一旦把它丢进层级森严、派系林立的大型传统企业，情况就会变得极度微妙。
谁来为失控的算力账单埋单？
当一个不懂技术的高管在会话里随口插了一句外行话，导致智能体把刚刚调好的上下文全盘污染，这个责任算在谁头上？
当不同部门的指令发生根本性对立，底层的请求调度队列真的能代替人类管理层的政治妥协吗？
技术可以砸碎软件层面的孤岛，但砸不碎人性的猜忌与防备。
11.jpg

但这绝不妨碍这次更新成为智能体发展史上的一座重要界碑。
它打破了那种把智能体当成孤单宠物的狭隘认知。
它让所有人看清楚了，人工智能最凶悍的力量，在于把四散在孤岛里的普通人重新连成一片辽阔的大陆。
当展台上的两台电脑同时亮起，那尊三倍大的自由女神像在屏幕上拔地而起的时候，旧时代的丧钟就已经被彻底敲响。
那些习惯了坐在孤岛里各自为政的人，是时候走出去了。
